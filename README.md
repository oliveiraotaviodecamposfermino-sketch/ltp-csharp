# LTP C# — Exercícios de Linguagem e Técnicas de Programação

Repositório com os exercícios e materiais de aula desenvolvidos na disciplina **Linguagem e Técnicas de Programação**, ministrada pelo professor **Matheus Eloy Franco**, no curso de Sistemas de Informação (IFSULDEMINAS — Campus Machado).

## Sobre

Aqui ficam guardados os códigos em C# produzidos ao longo da disciplina, incluindo:

- Exercícios resolvidos na plataforma [beecrowd](https://www.beecrowd.com.br/)
- Exemplos e atividades trabalhadas em aula

## Estrutura

| Pasta/Arquivo | Descrição |
|---|---|
| `beecrowd/` | Exercícios numerados resolvidos na plataforma beecrowd |
| `exercicios-aula/` | Atividades e exemplos propostos em aula |
